About This Survey

Welcome to the Alt Text Survey!

This survey is designed to collect feedback on the accessibility and quality of alt text descriptions for images. Alt text (alternative text) helps make web content accessible to people using screen readers and provides context when images cannot be displayed.

How It Works

  1. Browse Images: Click on any image in the gallery to open it
  2. Review Options: You'll see several alt text descriptions generated by different sources
  3. Vote: Select the alt text you think best describes the image
  4. See Results: Click "Submit & see results" to view how others voted

Your Privacy

Your responses are anonymous and stored locally. A unique participant ID is generated for your browser session to prevent duplicate votes, but no personal information is collected.

Goal

By participating, you're helping us understand which alt text generation methods work best, ultimately improving web accessibility for everyone.

More About Alternative Text

Alt text (alternative text) is an HTML attribute and is the written text that appears on the webpage in place of an image when it fails to load on a user’s screen. Alt text is used to describe the image and is helpful to visually impaired readers utilizing screen readers to access the content. A well written alt text also facilitates search engine optimization (SEO) by providing search engines essential information to help index an image correctly. The Cooper Hewitt guidelines provide guidance on the effective use of alt text.

About Alt Text Generative Options

The alternative text shown in the options are either written by humans, found on the site or generated by different AI tools. The AI tools used to generate alt text are

  • AHREFS: Established in 2010. AHREFS Image Alt Text Generator generates up to 3 variants, and accepts an optional description. The tool uses a language model that recognizes patterns and generates up to 3 variants of alt text based on the image and an optional description.
  • ASU Image Accessibility Creator: Created by ASU Online AI Labs. Arizona State University Image Accessibility Creator appears to be created to increase accessibility of ASU's course images. The tool accepts optional details about the image and provides long description as well as short alt text. Utilizes GPT-4 model by OpenAI
  • Popupsmart: Established in 2018. AI powered Alt Text Generator accepts the uploaded image and generates alt text.
  • ChatGPT: Utilizes GPT-5 model.
